\section{Introduction}
\label{sec:introduction}

Reservoir computing replaces recurrent parameter training by a fixed driven
dynamical system and learns only a readout
\citep{Jaeger2001,MaassNatschlagerMarkram2002}.  The simplification is
attractive when internal dynamics are expensive to optimize, but it moves a
large part of the learning problem into representation choice: memory,
reservoir width, random realization, and measurement quality all determine
whether the frozen features are useful.  In quantum reservoir computing
(QRC), these choices are also physical resources.  A useful learning theory
should therefore say not only how accurately one frozen predictor is evaluated,
but also why searching more frozen reservoirs or allocating more qubits can
improve the predictor that is ultimately returned.

We study causal temporal regression from a single dependent realization.  The
target is a continuous fading-memory functional of the input history, while
the learner observes only finite windows separated by a raw-time gap.  Three
implementation discrepancies are unavoidable: a finite window replaces the
infinite past, finite quantum measurements replace exact expectation values,
and a finite dependent sample replaces population risk.  Two representation
questions remain on top of them: what information survives the width-$n$
preprocessor, and how likely is a finite random pool to contain a useful frozen
realization?

QuaRK addresses these questions with a topology- and resource-aware QRC family.
An architecture $\arch=(n,R,\lambda_+)$ fixes the qubit width, number of
parallel reservoir branches, and upper memory endpoint.  Gaussian
preprocessing is coupled canonically across widths, without changing its
fixed-$n$ marginal law.  Each branch then draws a contraction rate and one
balanced random mixing circuit and freezes them.  The heterogeneous rates give
the parallel reservoir a multiscale memory profile.  A cycle interaction graph
both schedules the constant-depth entangling block and defines the measured
one- and two-qubit Pauli bank.  A nine-setting cover acquires that complete
bank, and the resulting features feed an RMS-normalized Mat\'ern RKHS readout
with a single Ivanov radius.  The kernel uses Euclidean feature distance divided
by the square root of feature dimension, so increasing $n$ or $R$ does not
change the kernel scale merely by concatenating more bounded coordinates.

Learning uses a finite frozen pool.  For one architecture, $S$ independent
designs are sampled, their measured features are cached, and the design and
readout are selected jointly by full-sample empirical-risk minimization.  No
gate axis, angle, or contraction rate is trained.  Using the same sample for
fitting and selection is not treated as free: the dependent-data bound is
uniform over all $S$ candidates and the complete Ivanov ball, so the
adaptivity of finite-pool search is charged explicitly through $\log S$ while
readout capacity is charged through $\Lambda$.

The representation analysis separates two notions of expressivity.  First,
the mixer analysis characterizes \emph{finite-resource feature enrichment}:
the encoding fixes the elementary trigonometric content, whereas the mixer and
graph determine how that content is distributed into multiqubit observables.
This does not assert that more entanglement always improves performance or
that mixing enlarges the asymptotic hypothesis class.  Second, for a fixed
Gaussian projection, we define the best population excess risk achievable
by any continuous fading-memory predictor that sees the complete projected
history.  This \emph{projection-information floor} isolates what width can and
cannot recover.  Under the canonical Gaussian prefix coupling the floor is
nonincreasing in $n$, and it is zero almost surely once $n\geq d$; strict
improvement at every width is neither required nor claimed.  We then show that
finite spatial multiplexing of QuaRK coordinates followed by finite-norm
Mat\'ern readouts can approach this floor arbitrarily closely.  Thus the
asymptotic approximation obstruction at fixed width is exactly the information
discarded by preprocessing, not an additional limitation of the frozen
reservoir family.

This support-level approximation result is then connected to random search.
Whenever an architecture has a strictly good support design, continuity of the
causal reservoir map gives an open neighborhood of equally good designs and
therefore positive random-design mass $\hitMass$.  An i.i.d. pool of
size $S$ misses every such design with probability
$(1-\hitMass)^S$.  Combining this exact pool-coverage term with the
uniform ERM oracle inequality, grouped-measurement fidelity, and contractive
finite-window fidelity yields an end-to-end excess-risk bound for the
operational predictor actually returned.  The result gives $S$ two transparent
roles: exponentially better representation coverage and a logarithmic
statistical selection price.

A finite-data Johnson--Lindenstrauss result remains useful, but for a different
question.  It supplies a width logarithmic in the number of raw inputs required
to preserve the geometry of the particular observed sample.  We keep this
statement separate from the population approximation theorem rather than
interpreting finite-sample geometry preservation as a prediction guarantee.

Finally, we formulate a controlled temporal benchmark that varies dependence,
input dimension, memory depth, nonlinear degree, and spatiotemporal interaction
structure while preserving compact inputs and a known causal target.  The
resource study is organized around the same quantities that appear in the
theory: $n$, $R$, $M$, $S$, and $\lambda_+$.  The empirical question is not
simply whether a quantum reservoir can fit a task, but which temporal processing
demands justify each additional resource.  State-preparation counts are kept
separate from per-run circuit resources: a measured trajectory has width
$O(n)$ and depth $O(w)$ under the declared reusable-hardware convention,
whereas grouped acquisition requires $9RM$ branch-circuit runs per candidate
window.

\paragraph{Contributions.}
The paper makes three contributions.  First, it introduces a topology-aligned
frozen QRC family with explicit architecture, random-design law, and grouped
measurement cost, together with a graph-local operator-spreading result that
explains what the nontrivial mixer and edge-observable bank add beyond the
identity support point at finite resources.  Second, it gives a width-resolved
approximation theorem, positive-mass and finite-pool coverage results, and a
dependent-data ERM certificate that combine into an end-to-end
resource-to-performance bound for the selected predictor; under geometric
mixing, an explicit logarithmic-in-$N$ gap rule keeps the coupling penalty
controlled.  Third, it provides a controlled evaluation framework for
relating temporal-processing difficulty to $(n,R,M,S,\lambda_+)$ and directly
ablating mixer/observable mechanisms, while keeping finite-data JL geometry
conceptually separate from population prediction.
