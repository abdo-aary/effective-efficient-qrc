\section{Theory}
\label{sec:theory}

The method naturally leads to a sequence of analytical questions. How wide
must the encoded input be on a finite dataset? Does the reservoir state depend
on an arbitrary initialization? How accurately does a finite window represent
the causal infinite-history feature? How does this approximation interact with
the Mat\'ern readout, how does temporal dependence change the learning rate,
and what price is paid when validation selects among finitely many candidate
configurations? We answer these questions in the same order as the pipeline and
then return to the finite-shot cost of estimating the observable features. Unless
stated otherwise, the results use the analytical scope specified in
\cref{sec:analytical-scope}. Complete proofs are collected in
\cref{app:proofs}.

\subsection{Finite-set projection}

\begin{proposition}[Finite-set JL projection; adapted from
\citealp{DasguptaGupta2003,Woodruff2014}]
\label{prop:jl}
Let \(\mathcal P\subset\R^d\) contain \(M\geq2\) points. For
\(\varepsilon,\delta\in(0,1)\), there is a universal constant \(C>0\) such
that, if
\[
    n\geq
    C\varepsilon^{-2}\log\!\left(\frac{M}{\delta}\right)
\]
and \(\Pi_{ij}\overset{\mathrm{i.i.d.}}{\sim}\mathcal N(0,1/n)\), then with
probability at least \(1-\delta\),
\[
    (1-\varepsilon)\norm{u-v}_2^2
    \leq\norm{\Pi u-\Pi v}_2^2
    \leq(1+\varepsilon)\norm{u-v}_2^2
\]
simultaneously for all \(u,v\in\mathcal P\). For the points occurring in
\(N\) windows of length \(w\), one may take \(M\leq wN\).
\end{proposition}

For a prescribed finite set and distortion level, the proposition makes the
encoded dimension logarithmic in the number of points rather than tied directly
to \(d\). If the point set is the realized sample, the statement is read
conditionally on that set, with \(\Pi\) drawn independently. This JL event is
separate from the learning-theorem event unless their failure probabilities are
combined explicitly. The statement concerns the projection before angle
encoding: it neither guarantees that the final reservoir features are distinct
nor removes the \(d\)-dependent cost of applying \(\Pi\). Having accounted for
encoded width, we next study the temporal state generated from these inputs.

\subsection{Contraction, causal states, and finite windows}

\begin{lemma}[Exact trace-norm contraction]
\label{lem:contraction}
For every sub-reservoir \(r\), input \(x\), and pair of density operators
\(\rho,\rho'\),
\begin{equation}
    \traceNorm{T_{r,x}(\rho)-T_{r,x}(\rho')}
    =
    \lambda_r\traceNorm{\rho-\rho'}.
    \label{eq:exact-contraction}
\end{equation}
Consequently, for each input history there is a unique causal state obtained
as the initialization time tends to \(-\infty\). Under the measurability
condition in \cref{sec:analytical-scope}, the causal-state map is measurable.
Two trajectories driven by the same last \(w\) inputs satisfy
\begin{equation}
    \traceNorm{\rho_0^{(r)}-\rho_0^{\prime(r)}}
    \leq2\lambda_r^w.
    \label{eq:state-forgetting}
\end{equation}
\end{lemma}

The state-level estimate immediately controls the observable representation
used by the learner.

\begin{proposition}[Finite-window feature error]
\label{prop:feature-truncation}
For every input history,
\begin{align}
    \norm{\PhiInf(x_{-\infty:0})-\PhiWin(x_{-w+1:0})}_2
    &\leq
    2\sqrt{|\cO|\sum_{r=1}^R\lambda_r^{2w}}
    \label{eq:feature-truncation}\\
    &\leq
    2\sqrt{R|\cO|}\,\lambdaMax^w,
    \qquad
    \lambdaMax:=\max_r\lambda_r.
\end{align}
\end{proposition}

Together, \cref{lem:contraction,prop:feature-truncation} show that the reservoir
has a unique input-determined causal state and that a finite-window feature
vector approaches its infinite-history counterpart geometrically. The
parameters \(\lambda_r\) therefore expose a worst-case memory scale, while the
window length \(w\) controls the corresponding approximation error. The next
step is to determine how this feature error affects the kernel readout.

\subsection{Mat\'ern stability and truncation of loss}

\begin{lemma}[Mat\'ern RKHS section stability; derived from
\citealp{Genton2001,PorcuEtAl2024}]
\label{lem:matern-stability}
Let \(\kappa\) be the normalized Mat\'ern kernel in
\cref{eq:matern-profile,eq:matern-kernel} with \(\nu>1\). Then
\begin{equation}
    \norm{\kappa(z,\cdot)-\kappa(z',\cdot)}_{\cH_\kappa}
    \leq
    \frac1{\xi}\sqrt{\frac{\nu}{\nu-1}}\norm{z-z'}_2.
    \label{eq:matern-section-lipschitz}
\end{equation}
\end{lemma}

\begin{corollary}[Prediction and loss truncation]
\label{cor:loss-truncation}
For every \(h\in\Hball\),
\begin{align}
    \abs{h(\PhiInf)-h(\PhiWin)}
    &\leq
    \frac{2\Lambda}{\xi}
    \sqrt{
      \frac{\nu|\cO|}{\nu-1}
      \sum_{r=1}^R\lambda_r^{2w}
    },
    \label{eq:prediction-truncation}\\
    \abs{\risk_\infty(h)-\risk_w(h)}
    &\leq
    \tau_w,
    \label{eq:risk-truncation}
\end{align}
where
\begin{equation}
    \tau_w
    :=
    \frac{4\Lambda(\Lambda+\Upsilon)}{\xi}
    \sqrt{
      \frac{\nu|\cO|}{\nu-1}
      \sum_{r=1}^R\lambda_r^{2w}
    }.
    \label{eq:tau-window}
\end{equation}
\end{corollary}

The corollary converts dynamical forgetting into a uniform approximation of
predictions and squared risk over the RKHS ball. This term will appear
additively in the learning bound. In particular, increasing the sample size
alone cannot remove \(\tau_w\) when \(w\) and the reservoir parameters are held
fixed.

\subsection{Conditional interpolation capacity}

The truncation result concerns stability of a bounded readout. A separate
question is how much norm is needed to fit a finite set of exact features.

\begin{theorem}[Conditional finite-sample interpolation; cf.
\citealp{Aronszajn1950,KimeldorfWahba1971,HofmannScholkopfSmola2008}]
\label{thm:interpolation}
Let \(z_i=\PhiWin(x_i)\in\R^p\), \(i\in[N]\), be pairwise distinct exact
feature vectors, and let \(K_{ij}=\kappa(z_i,z_j)\). The Mat\'ern Gram matrix
\(K\) is positive definite. If \(\bm y\neq0\), define
\[
    \Lambda_\star
    :=
    \sqrt{\bm y^\top K^{-1}\bm y}.
\]
Then there is a unique minimum-norm interpolant
\(h_\star\in\cH_\kappa\) with
\(\norm{h_\star}_{\cH_\kappa}=\Lambda_\star\) and
\(h_\star(z_i)=y_i\) for all \(i\). Therefore:
\begin{enumerate}
    \item for \(\Lambda\geq\Lambda_\star\),
    \[
        \min_{\norm{h}_{\cH_\kappa}\leq\Lambda}
        \erisk_{N,w}(h)=0;
    \]
    \item for \(0\leq\Lambda\leq\Lambda_\star\),
    \begin{equation}
        \min_{\norm{h}_{\cH_\kappa}\leq\Lambda}
        \erisk_{N,w}(h)
        \leq
        \left(1-\frac{\Lambda}{\Lambda_\star}\right)^2
        \frac{\norm{\bm y}_2^2}{N}.
        \label{eq:conditional-interpolation}
    \end{equation}
\end{enumerate}
If \(\bm y=0\), the zero function interpolates with norm zero.
\end{theorem}

The theorem isolates the capacity of the Mat\'ern readout: once the exact
feature vectors are distinct, a finite RKHS norm suffices to interpolate them,
and scaling the interpolant gives a constructive training-error bound below
that norm. Pairwise distinctness is an assumption of the result; neither the JL
projection nor reservoir contraction guarantees it. This distinction is
important because interpolation capacity alone says nothing about test risk.
We now turn to that statistical question.

\subsection{Dependence of strided windows}

The learning sample is the window process \((W_j)\), not the raw process
\((Z_t)\). The following lemma translates their mixing coefficients by tracking
the first raw-time index appearing in a future window.

\begin{lemma}[Mixing coefficient of the window process]
\label{lem:window-mixing}
Let \(W\) be the process in \cref{eq:window-process} with stride \(s=w+g\).
For every integer \(a\geq1\),
\begin{equation}
    \beta_W(a)
    \leq
    \beta_Z(as-w).
    \label{eq:window-mixing}
\end{equation}
In particular, \(\beta_W(1)\leq\beta_Z(g)\).
\end{lemma}

The first raw input in a window at lag \(a\) occurs at \(as-w+1\). The displayed
bound is conservative by one time index under \cref{eq:beta-definition}, using
monotonicity of beta-mixing coefficients. It supplies the dependence term
needed by the independent-block construction.

\subsection{Generalization with dependent windows}

For a sample \(\cS_\mu=(\widetilde W_1,\ldots,\widetilde W_\mu)\), define the
empirical Rademacher complexity using the convention
\begin{equation}
    \hRad_{\cS_\mu}(\cF)
    :=
    \E_{\bm\sigma}\!\left[
      \sup_{f\in\cF}
      \abs{\frac2\mu\sum_{j=1}^\mu\sigma_j f(\widetilde W_j)}
    \right],
    \quad
    \sigma_j\overset{\mathrm{i.i.d.}}{\sim}\mathrm{Unif}\{-1,+1\}.
    \label{eq:rademacher-definition}
\end{equation}
This is the absolute-value convention used by
\citet{MohriRostamizadeh2008}; keeping it explicit avoids hidden factor or
centering changes when their theorem is specialized. For a length
\(N=2\mu a\) sequence of windows, \(\cS_\mu\) denotes one fixed position from
each of the \(\mu\) odd blocks of length \(a\). Let
\[
    \cF_\Lambda
    :=
    \set{
      (x_{-w+1:0},y)
      \mapsto
      (h(\PhiWin(x_{-w+1:0}))-y)^2:
      h\in\Hball
    }.
\]

\begin{theorem}[One-sided risk bound for beta-mixing windows; adapted from
\citealp{MohriRostamizadeh2008}]
\label{thm:generalization}
Under the analytical scope of \cref{sec:analytical-scope}, suppose that \(Z\)
is stationary and beta mixing. Let \(N=2\mu a\), with \(\mu,a\in\N\), and set
\begin{equation}
    \delta'
    :=
    \delta-4(\mu-1)\beta_Z(as-w).
    \label{eq:delta-prime}
\end{equation}
For every \(\delta\in(0,1)\) satisfying \(\delta'>0\), with probability at
least \(1-\delta\), simultaneously for all \(h\in\Hball\),
\begin{equation}
    \risk_\infty(h)
    \leq
    \erisk_{N,w}(h)
    +\hRad_{\cS_\mu}(\cF_\Lambda)
    +3(\Lambda+\Upsilon)^2
      \sqrt{\frac{\log(4/\delta')}{2\mu}}
    +\tau_w.
    \label{eq:empirical-rad-bound}
\end{equation}
\end{theorem}

Define the source-convention squared-loss complexity constant
\begin{equation}
    C_{\Lambda,\Upsilon}
    :=8\Lambda(\Lambda+\Upsilon)+2\Upsilon^2.
    \label{eq:loss-complexity-constant}
\end{equation}

\begin{corollary}[Closed-form RKHS bound; using the contraction principle of
\citealp{BartlettMendelson2002}]
\label{cor:closed-generalization}
Under the conditions of \cref{thm:generalization}, with the same probability,
simultaneously for all \(h\in\Hball\),
\begin{align}
    \risk_\infty(h)
    \leq\erisk_{N,w}(h)
    &+\frac{C_{\Lambda,\Upsilon}}{\sqrt{\mu}}
    +3(\Lambda+\Upsilon)^2
      \sqrt{\frac{\log(4/\delta')}{2\mu}}
    \notag\\
    &+
    \frac{4\Lambda(\Lambda+\Upsilon)}{\xi}
    \sqrt{
      \frac{\nu|\cO|}{\nu-1}
      \sum_{r=1}^R\lambda_r^{2w}
    }.
    \label{eq:closed-generalization}
\end{align}
\end{corollary}

The bound decomposes causal true risk into finite-window training risk, two
stochastic terms based on the effective block count
\(\mu=N/(2a)\), and the deterministic truncation term \(\tau_w\). Its
uniformity over the fixed RKHS ball includes fixed-\(\eta\) KRR through
\cref{eq:krr-norm-bound}, with \(\Lambda=\Upsilon/\sqrt\eta\). The statement is
one-sided, and the condition \(\delta'>0\) makes the dependence--sample-size
trade-off explicit: holding \(a=1\) while increasing \(N\) need not preserve
the confidence condition.

\subsection{Selection from a finite candidate family}

The preceding bound fixes the featurizer and kernel before observing the
sample. Empirical studies, however, commonly compare a finite grid of reservoir
and readout configurations and select one using validation performance. The
next result makes the bound simultaneous over such a predeclared family.

\begin{corollary}[Finite-family model selection; finite-union argument based on
\citealp{McDiarmid1989,BartlettMendelson2002}]
\label{cor:finite-family-selection}
Let \(\mathfrak C=\{1,\ldots,L\}\), with \(L\geq1\), be a finite,
measurable family fixed before observing the sample, including every candidate's
random seed and preprocessing map. All candidates share the same window length
\(w\), stride \(s\), and block parameters \(N=2\mu a\). Candidate
\(\ell\) specifies an exact causal and finite-window featurizer
\(\Phi_\infty^{(\ell)},\Phi_w^{(\ell)}\), a normalized Mat\'ern kernel
\(\kappa_\ell\) with \(\nu_\ell>1\), and an RKHS ball
\[
    \cH_\ell
    :=
    \set{h\in\cH_{\kappa_\ell}:\norm{h}_{\cH_{\kappa_\ell}}\leq\Lambda_\ell}.
\]
Let \(\tau_{w,\ell}\) be its truncation term from
\cref{cor:loss-truncation}, define
\[
    B_{\mathfrak C}
    :=
    \max_{\ell\in[L]}(\Lambda_\ell+\Upsilon)^2,
    \qquad
    A_{\mathfrak C}
    :=
    \max_{\ell\in[L]}
    \left[8\Lambda_\ell(\Lambda_\ell+\Upsilon)+2\Upsilon^2\right],
\]
and retain \(\delta'=\delta-4(\mu-1)\beta_Z(as-w)>0\). Then, with
probability at least \(1-\delta\), simultaneously for every
\(\ell\in[L]\) and \(h\in\cH_\ell\),
\begin{align}
    \risk_{\infty,\ell}(h)
    \leq
    \erisk_{N,w,\ell}(h)
    &+\frac{A_{\mathfrak C}}{\sqrt\mu}
    +2B_{\mathfrak C}
      \sqrt{\frac{2\log L}{\mu}}
    \notag\\
    &+3B_{\mathfrak C}
      \sqrt{\frac{\log(4/\delta')}{2\mu}}
    +\tau_{w,\ell}.
    \label{eq:finite-family-bound}
\end{align}
Here \(\risk_{\infty,\ell}\) and \(\erisk_{N,w,\ell}\) denote the risks
induced by candidate \(\ell\). Consequently, the same event controls any
measurable, sample-dependent selector \((\widehat\ell,\widehat h)\) whose
output belongs to \(\bigcup_{\ell=1}^L\{\ell\}\times\cH_\ell\).
\end{corollary}

The additional term scales as \(\sqrt{\log L/\mu}\), so validation-based
selection among a declared finite grid costs only logarithmically in the number
of candidates. The result can cover finite choices of reservoir parameters,
random seeds, observable families, and Mat\'ern readout parameters, provided
the candidate list and its preprocessing are fixed in advance and the candidates
share the window scheme used by the blocking argument. It does not cover
continuous optimization, adaptive expansion of the search space, or
sample-estimated preprocessing that is not included in the finite family.

For geometric mixing, the block length can be increased slowly enough to
control the coupling penalty without reducing the effective sample size too
severely.

\begin{corollary}[Geometrically mixing case]
\label{cor:geometric-mixing}
Suppose, in addition, that
\(\beta_Z(q)\leq\beta_0e^{-cq}\) for constants \(\beta_0,c>0\), and keep
\(w\) and \(s\) fixed. For a compatible sample size \(N=2\mu a\), choose an
integer \(a\leq N/2\) satisfying
\begin{equation}
    a
    \geq
    \left\lceil
      \max\left\{
        1,\,
        \frac1{cs}
        \log\!\left(\frac{4\beta_0e^{cw}N}{\delta}\right)
      \right\}
    \right\rceil.
    \label{eq:geometric-block-choice}
\end{equation}
Then \(\delta'\geq\delta/2\). For fixed
\(\Lambda,\Upsilon,\delta,\beta_0,c,w,s\), the two stochastic terms in
\cref{eq:closed-generalization} are
\[
    O\!\left(\sqrt{\frac{\log(N/\delta)}{N}}\right).
\]
If the available sample size is not divisible by \(2a\), retain
\(N_a=2a\lfloor N/(2a)\rfloor\) observations (provided \(N_a\geq2a\)); at most
\(2a-1\) terminal observations are discarded. For fixed problem parameters,
the displayed choice satisfies \(a\leq N/2\) for all sufficiently large \(N\).
\end{corollary}

The corollary recovers an independent-like rate up to a logarithmic factor, but
it does not remove the finite-window term. A consistency result would require a
joint schedule for \(w\), \(s\), \(a\), and the readout class.

\subsection{Finite-shot local-observable estimation}

The preceding learning bound treats \(\PhiWin\) as an exact expectation vector.
On a measurement-based implementation, every coordinate must instead be
estimated from repeated preparations of the final reservoir state.

\begin{proposition}[Local-Pauli classical-shadow requirement; adapted from
\citealp{HuangKuengPreskill2020}]
\label{prop:shadows}
Suppose \(\cO\) contains \(M=|\cO|\) nonidentity Pauli strings of weight at
most \(k\). In each snapshot, measure every qubit in an independently and
uniformly selected \(X\), \(Y\), or \(Z\) basis. There is a universal
constant \(C_{\mathrm{sh}}>0\) such that
\begin{equation}
    S
    \geq
    C_{\mathrm{sh}}\,3^k\varepsilon^{-2}
    \log\!\left(\frac{2M}{\delta_{\mathrm{sh}}}\right)
    \label{eq:shadow-samples}
\end{equation}
snapshots of one reservoir state suffice for simultaneous additive error at
most \(\varepsilon\) for all observables, with probability at least
\(1-\delta_{\mathrm{sh}}\).

For \(N\) windows and \(R\) separately prepared sub-reservoir states, the
choice
\begin{equation}
    S\geq
    C_{\mathrm{sh}}\,3^k\varepsilon^{-2}
    \log\!\left(\frac{2MNR}{\delta_{\mathrm{tot}}}\right)
    \label{eq:shadow-samples-total}
\end{equation}
gives the same coordinate-wise error simultaneously over all \(NR\) states,
by a union bound. This requires \(NRS\) state preparations and \(NRSw\)
temporal channel applications. Identity observables, if retained in a feature
ledger, are known exactly.
\end{proposition}

\begin{corollary}[Uniform stability of RKHS readouts to measurement error]
\label{cor:measurement-stability}
Suppose every coordinate of \(\widehat\Phi_w-\PhiWin\) has magnitude at most
\(\varepsilon\). On this deterministic event, the following inequalities hold
simultaneously for every \(h\in\Hball\):
\begin{align}
    \abs{h(\widehat\Phi_w)-h(\PhiWin)}
    &\leq
    \frac{\Lambda}{\xi}
    \sqrt{\frac{\nu R|\cO|}{\nu-1}}\,\varepsilon,
    \label{eq:shot-prediction}\\
    \abs{
      \ell(h(\widehat\Phi_w),y)
      -\ell(h(\PhiWin),y)
    }
    &\leq
    \frac{2\Lambda(\Lambda+\Upsilon)}{\xi}
    \sqrt{\frac{\nu R|\cO|}{\nu-1}}\,\varepsilon
    \label{eq:shot-loss}
\end{align}
whenever \(\abs y\leq\Upsilon\).
\end{corollary}

For the stated measurement ensemble, observable locality determines the
exponential factor \(3^k\), while the number of observables enters only
logarithmically. The perturbation corollary is uniform over the RKHS ball and therefore applies
to any already-chosen readout in that ball. It compares the same function on
exact and estimated features; it does not compare a readout retrained on noisy
features with the exact-feature estimator, nor does it cover physical errors in
state preparation and evolution. Those effects are separate from finite-shot
sampling.
