\section{Problem Setting}
\label{sec:problem-setting}

We first fix the causal prediction target and the dependent sample.  Keeping
these objects separate from the quantum model makes the later risk statements
unambiguous: there is one population target, one gapped finite-window sample,
and one dependence coefficient inherited from the original process.

\subsection{Causal fading-memory regression}

Let $\processZ=(\processZ_t)_{t\in\sZ}$ be stationary, with
$\processZ_t=(X_t,Y_t)$, $X_t\in\gX\subset\sR^d$, and
$Y_t\in[-\Upsilon,\Upsilon]$.  The input set $\gX$ is compact and
$\sZ_-:=\{\ldots,-2,-1,0\}$.  We write
$\vx^-=(\ldots,x_{-1},x_0)\in\HistorySpace$ for an input history.

The target is a measurable version $F^\star:\HistorySpace\to\sR$ of the
causal conditional mean,
\begin{equation}
    F^\star(X_{-\infty:0})
    =\E\!\left[Y_0\mid\sigma(X_t:t\leq0)\right]
    \quad\text{a.s.},
    \label{eq:causal-regression}
\end{equation}
with Bayes risk
$\risk^\star:=\E[(F^\star(X_{-\infty:0})-Y_0)^2]$.

Let $\vvarpi=(\varpi_\ell)_{\ell\geq0}$ be positive, nonincreasing, and satisfy
$\varpi_\ell\to0$.  The associated fading-memory metric is
\begin{equation}
    d_{\vvarpi}(\vu^-,\vv^-)
    :=\sup_{\ell\geq0}\varpi_\ell\norm{u_{-\ell}-v_{-\ell}}_2.
    \label{eq:fading-memory-metric}
\end{equation}
A functional has the fading-memory property (FMP) when it is continuous for
such a metric.  More generally, for any compact $\gA\subset\sR^k$, write
$\gFFMP(\gA)$ for the continuous fading-memory functionals on
$\gA^{\sZ_-}$ under the analogous weighted metric.  Because the weights tend
to zero, this is exactly continuity for the product topology, and
$\gA^{\sZ_-}$ is compact.  We abbreviate $\gFFMP:=\gFFMP(\gX)$ and equip it
with the uniform norm
\begin{equation}
    \normop{F}:=\sup_{\vx^-\in\HistorySpace}|F(\vx^-)|,
    \qquad F\in\gFFMP.
    \label{eq:uniform-norm}
\end{equation}
Throughout the paper, $F^\star\in\gFFMP$.  In particular, continuity on the
compact history space implies that sufficiently long terminal windows
approximate $F^\star$ uniformly.

\subsection{Gapped finite windows}

Only one finite realization of $\processZ$ is observed.  Following the
finite-window viewpoint used in reservoir risk analysis
\citep{GononGrigoryevaOrtega2020}, fix a window length $w\geq1$ and a raw-time
gap $g\geq0$, and set the stride $\Delta:=w+g$.  The labeled window process is
\begin{equation}
    \processW_j:=\bigl(X_{j\Delta-w+1:j\Delta},Y_{j\Delta}\bigr),
    \qquad j\in\sN.
    \label{eq:gapped-window-process}
\end{equation}
For the dependent-data argument we take an even sample size $N=2\mu$ and
write
\begin{equation}
    \Data_N:=(\processW_1,\ldots,\processW_N).
    \label{eq:even-window-sample}
\end{equation}
The parity split therefore contains $\mu$ windows on each side.  This evenness
is only a proof device; empirical fitting need not otherwise privilege even
sample sizes.  A realized sample is denoted by
$\widetilde\Data_N=(\widetilde\processW_1,\ldots,\widetilde\processW_N)$ with
$\widetilde\processW_j=(\vx_{j\Delta-w+1:j\Delta},y_{j\Delta})$.

\subsection{Absolute regularity}

For sigma-algebras $\gA$ and $\gB$, let $\beta(\gA,\gB)$ denote their
absolute-regularity coefficient.  The coefficients of the original process
are
\begin{equation}
    \beta_{\processZ}(q)
    :=\sup_{t\in\sZ}
      \beta\!\left(\sigma(\processZ_u:u\leq t),
                   \sigma(\processZ_u:u\geq t+q)\right),
    \qquad q\geq0.
    \label{eq:beta-original-process}
\end{equation}
We call $\processZ$ beta mixing if $\beta_{\processZ}(q)\to0$.  Since adjacent
windows are separated by the raw-time gap $g$, monotonicity of absolute
regularity under sigma-algebra inclusion gives the only window-mixing relation
used later,
\begin{equation}
    \beta_{\processW}(1)\leq\beta_{\processZ}(g).
    \label{eq:adjacent-window-mixing}
\end{equation}
Thus the sampling protocol exposes the dependence penalty directly through
$g$ and $\beta_{\processZ}(g)$ rather than hiding it in an effective sample
size.
