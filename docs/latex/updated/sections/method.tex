\section{Method}
\label{sec:method}

\textsc{QuaRK} turns a temporal window into a kernel input through four stages.
The raw observations are first projected and encoded as rotations. Each
projected sequence then drives several reset-contractive quantum reservoirs.
Local observable expectations from their final states are concatenated, and a
Mat\'ern kernel ridge-regression readout is trained on the resulting vectors.
We describe the stages in this order and conclude with an end-to-end resource
ledger.

\subsection{Finite-set projection and angle encoding}

For resource accounting, let \(\mathcal P\subset\R^d\) be the set of all
individual time-point vectors appearing in the finite collection of windows to
be processed, so \(|\mathcal P|\leq wN\). Independently of these points, and for
a chosen register width \(n\), draw
\[
    \Pi\in\R^{n\times d},
    \qquad
    \Pi_{ij}\stackrel{\mathrm{i.i.d.}}{\sim}\mathcal N(0,1/n),
\]
and set \(z=\Pi x\). Each coordinate is converted to a bounded angle, for
example \(\theta(z_j)=\pi\tanh(z_j)\), and encoded by a one-qubit
\(R_y(\theta(z_j))\) rotation.

The finite-set JL statement in \cref{prop:jl} allows the encoded dimension to
be chosen from a distortion and failure-probability target rather than by
setting \(n=d\). This width interpretation applies only to the projected finite
set: the dense multiplication still costs \(O(nd)\) operations per time point,
and the subsequent angle encoding and reservoir evolution are nonlinear. The
encoded rotations now provide the input layer of each reservoir update.

\subsection{Reset-contractive quantum dynamics}

Sub-reservoir \(r\) applies the input-dependent unitary
\begin{equation}
    V_r(x)
    =
    W_r
    \bigotimes_{j=1}^n R_y\!\left(\theta((\Pi x)_j)\right),
    \label{eq:input-unitary}
\end{equation}
where \(W_r\) is a fixed topology-constrained unitary. Its parameters are drawn
once and then held fixed. A generic three-qubit instance is shown in
\cref{fig:unitary}; the controlled links represent a chosen entangling pattern
rather than a particular device-native gate set.

After the unitary, the state is partially replaced by a fixed reset state. On
an arbitrary operator \(A\), define
\begin{equation}
    T_{r,x}(A)
    :=
    \lambda_r V_r(x) A V_r(x)^\dagger
    +(1-\lambda_r)\Tr[A] \,\rhoreset,
    \qquad 0\leq\lambda_r<1.
    \label{eq:reset-channel}
\end{equation}
The map \(A\mapsto\Tr[A]\rhoreset\) is a replacement channel. A Kraus
representation is given in \cref{app:technical-background}, so it is completely
positive and trace preserving; consequently, so is \(T_{r,x}\). For a density
operator \(\rho\), this reduces to
\[
    T_{r,x}(\rho)
    =
    \lambda_r V_r(x)\rho V_r(x)^\dagger
    +(1-\lambda_r)\rhoreset.
\]
The parameter \(\lambda_r\) sets the worst-case memory scale: values near one
retain more of the previous state, whereas smaller values place more weight on
the reset state.

The replacement channel admits the ideal dilation in
\cref{fig:reset-dilation}. For
\(\rhoreset=\lvert+\rangle\!\langle+\rvert^{\otimes n}\), an \(n\)-qubit reset
register is prepared in \(\lvert+\rangle^{\otimes n}\), and a coin qubit
controls swaps between the reservoir and reset registers. Discarding the coin
and reset registers produces the mixture in \cref{eq:reset-channel}.

For a length-\(w\) window, the recursion starts from
\(\rho_{\mathrm{init}}^{(r)}\) and applies \cref{eq:reset-channel} once per time
point. Moving the initialization into the remote past defines the causal state;
\cref{lem:contraction} will show that this limit exists and is unique.

\subsection{Reservoir multiplexing and observable features}

The \(R\) sub-reservoirs produce a tuple of final states,
\[
    \bigl(\rho^{(1)}_{w,0},\ldots,\rho^{(R)}_{w,0}\bigr),
\]
rather than a tensor-product state. They may be run in parallel on separate
registers or sequentially on reused hardware. Parallel execution multiplies
peak quantum width, whereas sequential execution keeps the reservoir width at
\(n\) qubits but multiplies runtime and state preparations.

For each reservoir, the observables in \(\cO\) are evaluated and concatenated
as in \cref{eq:window-feature}, producing a vector of dimension
\(p=R|\cO|\). The exact expectations define the analytic feature map used in
the kernel and in the main learning theorem. Their finite-shot estimates are
introduced later in \cref{prop:shadows,cor:measurement-stability}. Once the
quantum states have been reduced to this classical vector, the remaining
learning stage is an ordinary kernel method.

\subsection{Mat\'ern kernel readout}

For distance \(r\geq0\), smoothness \(\nu>1\), and length scale \(\xi>0\), let
\begin{equation}
    \varphi_{\nu,\xi}(r)
    :=
    \frac{2^{1-\nu}}{\Gamma(\nu)}
    \left(\frac{\sqrt{2\nu}\,r}{\xi}\right)^\nu
    K_\nu\!\left(\frac{\sqrt{2\nu}\,r}{\xi}\right),
    \label{eq:matern-profile}
\end{equation}
where \(K_\nu\) is the modified Bessel function of the second kind. With
\(\varphi_{\nu,\xi}(0)=1\), define
\begin{equation}
    \kappa(z,z')
    :=
    \varphi_{\nu,\xi}\!\left(\norm{z-z'}_2\right).
    \label{eq:matern-kernel}
\end{equation}
This is a classical kernel evaluated after feature extraction. We use its
strict positive definiteness to study interpolation and its spectral second
moment to control sensitivity to feature perturbations.

Given exact training features \(z_i=\PhiWin(x_i)\), kernel ridge regression
solves
\begin{equation}
    \min_{h\in\cH_\kappa}
    \frac1N\sum_{i=1}^N(h(z_i)-y_i)^2
    +\eta\norm{h}_{\cH_\kappa}^2.
    \label{eq:krr-objective}
\end{equation}
By the representer theorem \citep{KimeldorfWahba1971,ScholkopfSmola2002},
\(\widehat h_\eta(\cdot)=\sum_i\alpha_i\kappa(z_i,\cdot)\), where
\[
    \bm\alpha=(K+N\eta I)^{-1}\bm y.
\]
When \(\abs{y_i}\leq\Upsilon\), comparing the objective at
\(\widehat h_\eta\) with the zero function gives
\begin{equation}
    \eta\norm{\widehat h_\eta}_{\cH_\kappa}^2
    \leq \frac1N\sum_{i=1}^N y_i^2
    \leq \Upsilon^2,
    \qquad
    \norm{\widehat h_\eta}_{\cH_\kappa}
    \leq \frac{\Upsilon}{\sqrt\eta}.
    \label{eq:krr-norm-bound}
\end{equation}
Thus fixed-\(\eta\) KRR belongs to the RKHS ball used in
\cref{sec:theory} with \(\Lambda=\Upsilon/\sqrt\eta\), provided the featurizer,
kernel parameters, and \(\eta\) are fixed independently of the analyzed
sample. The finite-family result in \cref{cor:finite-family-selection} also
allows these quantities to be selected from a predeclared finite grid. Dense
KRR requires \(O(N^2)\) kernel storage and \(O(N^3)\) naive linear-algebra time,
which remains part of the end-to-end cost.

\subsection{Resource summary}

The stages above expose different bottlenecks. \Cref{tab:resources} separates
peak quantum width from repeated temporal evolution and from classical
post-processing. In particular, one snapshot of a final length-\(w\) reservoir
state requires replaying all \(w\) channel updates. Projected inputs may be
cached, but the quantum evolution must be repeated for each state preparation.

This decomposition will reappear in the theory: the projection controls encoded
width, contraction controls the finite-history approximation, RKHS geometry
controls the readout, dependence determines the effective sample size, and
observable locality controls the measurement budget.
