\section{Out-of-Scope Chaotic Stress Tests}
\label{app:chaotic-stress}

The main analysis concerns stationary beta-mixing input--output processes.  The
experiments in this appendix deliberately leave that scope and ask whether the
architecture remains useful on deterministic systems with sensitive dependence
on initial conditions.  The systems are therefore empirical stress tests, not
examples covered by \cref{thm:generalization}.  We use the Lorenz--63 flow
\citep{Lorenz1963} and the Mackey--Glass delay equation
\citep{MackeyGlass1977}, both of which are standard nonlinear temporal
benchmarks.

\subsection{Lorenz--63 system}
\label{app:lorenz63}

The Lorenz--63 state \(U(t)=(u_1(t),u_2(t),u_3(t))\) satisfies
\begin{equation}
\begin{aligned}
  \dot u_1 &= \sigma(u_2-u_1),\\
  \dot u_2 &= u_1(\rho-u_3)-u_2,\\
  \dot u_3 &= u_1u_2-\beta u_3,
\end{aligned}
\qquad
(\sigma,\rho,\beta)=\left(10,28,\frac83\right).
\label{eq:lorenz63}
\end{equation}
Trajectories are generated with a fourth-order Runge--Kutta integrator using
step size \(h_{\mathrm{int}}=0.01\), followed by a burn-in of \(5000\)
integration steps.  To vary the effective prediction difficulty, the retained
trajectory is sampled at
\[
  \Delta t\in\{0.02,0.05,0.10\}.
\]
The observed input is the bounded state
\[
  X_j=\tanh\!\left(D^{-1}U(j\Delta t)\right),
\]
where the diagonal scale \(D\) is fixed from a separate calibration trajectory
and is not estimated from the test segment.

For a unit vector \(u\in\R^3\), the scalar \(q\)-step target is
\begin{equation}
  Y_{j,q}^{\mathrm{L63}}
  :=u^\top X_{j+q},
  \qquad q\in\{1,5,10,20\}.
  \label{eq:lorenz-target}
\end{equation}
A second partial-observation task gives the learner only
\((X_j^{(1)},X_j^{(2)})\) and asks it to predict the bounded third coordinate at
horizon \(q\).  This separates ordinary full-state forecasting from recovery
of an unobserved component.

\subsection{Mackey--Glass delay system}
\label{app:mackey-glass}

The scalar Mackey--Glass process is defined by the delay differential equation
\begin{equation}
  \dot x(t)
  =\frac{\beta_{\mathrm{MG}}x(t-\tau)}
          {1+x(t-\tau)^{n_{\mathrm{MG}}}}
   -\gamma_{\mathrm{MG}}x(t),
  \label{eq:mackey-glass}
\end{equation}
with
\[
  \beta_{\mathrm{MG}}=0.2,\qquad
  \gamma_{\mathrm{MG}}=0.1,\qquad
  n_{\mathrm{MG}}=10,
  \qquad \tau\in\{17,30\}.
\]
The delay equation is integrated with step size \(0.1\), using a constant
positive history on \([-\tau,0]\), discarding the first \(5000\) integration
steps and sampling every ten integration steps.  The bounded observation is
\(X_j=\tanh(c_x(x_j-m_x))\), where \(m_x\) and \(c_x\) are fixed from a
separate calibration trajectory.  The forecast targets are
\begin{equation}
  Y_{j,q}^{\mathrm{MG}}:=X_{j+q},
  \qquad q\in\{1,5,10,20\}.
  \label{eq:mackey-glass-target}
\end{equation}
The two delay values provide different temporal-complexity regimes without
changing the readout task.

\subsection{Stress-test protocol}
\label{app:chaotic-protocol}

For both systems, five predeclared initial-condition seeds are used.  Each
trajectory is split chronologically into training, validation, and test
segments with a guard interval of at least the largest prediction horizon
between adjacent segments.  Windows never cross a split boundary.  Observation
noise is added after trajectory generation at levels
\[
  \sigma_{\mathrm{obs}}\in\{0,0.01,0.05\}
\]
and is generated independently across methods from shared seeds.

The principal methods are \textsc{QuaRK}, ESN plus Mat\'ern KRR, and
matched-dimensional random nonlinear features plus Mat\'ern KRR.  Candidate
families and readout grids are predeclared exactly as in
\cref{sec:empirical-protocol}.  We report NRMSE by horizon, the relative skill
against a persistence predictor, and the horizon at which that skill falls
below a predeclared threshold.  No mixing coefficient, effective-block count,
or theorem-based confidence statement is attached to these results.
